A program that writes one image summing up Thursday, 26 November 2026's world news to `/output/entry.png`: a newspaper front page dated 26 November 2026. Lead story: Shenzhou-24 docks at China's Tiangong space station with Muhammad Zeeshan Ali, the first Pakistani astronaut and the first foreign visitor to the station. Also covered: the Houthi drone strike on a Riyadh tower injuring 11, Wall Street tumbling as Nvidia leads an AI sell-off before Thanksgiving, and the Europe-Japan BepiColombo probe reaching Mercury after eight years — plus Colombia marking ten years of peace, India celebrating Constitution Day, and a quake shaking Nepal. The image is a whole JPEG, 1024 by 1024 pixels, under 1 MiB, and the program copies it byte for byte, so both runs write identical output.

## Run it

```sh
python3 main.py
```
